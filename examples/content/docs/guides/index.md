# Welcome to the Advanced Documentation

This is the documentation site for **Krate**, a custom static site generator built with Go.

## Getting Started

To get started, check out the [Getting Started guide](/docs/getting-started/).

## Features

- **Fast builds** — Parallel page building with dependency tracking
- **Markdown & MDX** — Write content in Markdown or MDX with JSX components
- **Tailwind CSS** — Utility-first CSS with Go-native class scanning
- **Hot reload** — Instant feedback during development
- **Plugin system** — Extend with Go plugins
