:::note
**Les traductions ne sont pas encore terminées.** La documentation française
(et les autres langues) est maintenue par la communauté : les contributions sont
les bienvenues.

En attendant, toute la documentation de référence est disponible en anglais —
consultez la [documentation anglaise](/docs/).
:::

## Contribuer à une traduction

Vous voulez aider ? Ouvrez une pull request ajoutant les fichiers sous
`packages/web/src/content/docs/<locale>/` (par exemple `fr/`), puis traduisez les
pages une par une. Le [guide de contribution](/docs/contributing/) décrit
le processus.
